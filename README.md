# Diploma Driver

Клиент водителя для дипломного проекта: карта, маршрут, информация о машине и статистика. Интерфейс использует React, TypeScript, Redux Toolkit и Yandex Maps JS API v3.

## Локальный запуск

1. Установите зависимости: `npm ci`.
2. Скопируйте `.env.example` в `.env`.
3. Замените `YOUR_YANDEX_MAPS_API_KEY` своим ключом Yandex Maps JS API v3.
4. Запустите backend проекта из [diploma-back](https://github.com/frendip/diploma-back). Клиент обращается к `http://localhost:4000/`.
5. Запустите клиент: `npm start`.

Для сборки: `npm run build`. После изменения `.env` перезапустите сервер разработки или пересоберите приложение.

## Настройка ключа карты

Ключ читается из `REACT_APP_YMAPS_API_KEY` и подставляется в `public/index.html` при сборке. `.env` и его локальные варианты исключены из Git; в репозитории хранится только шаблон `.env.example`.

Это клиентский ключ: он будет виден посетителю в собранной странице. Не используйте здесь серверные секреты. Настройте доступные ограничения ключа в кабинете провайдера под своё приложение.

Демонстрационные телефон и email в интерфейсе — заполнители. Для запуска нужен собственный ключ и работающий backend.
